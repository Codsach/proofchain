2. FEATURE OVERVIEW & ARCHITECTURE
----------------------------------
The Evidence Custody Chain ensures that from the moment evidence is uploaded, 
its cryptographic hand-offs are fully traceable, validated on-chain, and easily 
audited without compromising identity regulations.

- Custody Flow (Bottom-to-Top):
  - Start (Bottom): Evidence is uploaded by the Investigator, hashed, and anchored to 
    the Polygon Amoy blockchain.
  - Middle: Case is transferred between team members. Each hand-off requires a 
    reason, timestamps are generated, and a transfer hash is recorded on-chain.
  - End (Top): A final verdict is issued by the Analyst, locking the case status.

- Security & Anonymization (PRD REV-08):
  - Admins can inspect real names of all handlers.
  - Analysts see hand-off events with the Investigator's identity anonymized 
    (replaced with "Investigator (Anonymized)").
  - Guests on the public `/verify/[caseId]` page see zero names, seeing only roles 
    ("Investigator" or "Analyst") mapping directly to the immutable blockchain logs.

- Navigation Improvements:
  - Copyable Case ID: Clicking the ID badge in any table copies the full UUID to the 
    clipboard.
  - Direct Verification: A "Verify ↗" link directly in each list row bypasses 
    nested page clicking, taking users straight to the verify detail view.


3. THE PLANNING: SESSION-LINKED QUICK VERIFY SELECTION
------------------------------------------------------
To avoid requiring users to copy-paste or search Case IDs when they are already logged 
into the ProofChain console:

- Client Session Verification:
  - The public `/verify` lookup page will hook into `useAuth()` to check if a user is 
    logged in.
- Contextual Fetching:
  - If a user is logged in, the page will query the list of cases associated with their 
    role (Admin: `/api/admin/cases`, Analyst: `/api/cases/queue`, Investigator: `/api/cases`).
- Dynamic Select UI:
  - Render a drop-down selector "Quick Verify Your Cases" next to the search input.
  - Selecting a case immediately redirects the browser to `/verify/[caseId]`.
  - Public guests will still see the search box as a fallback.
